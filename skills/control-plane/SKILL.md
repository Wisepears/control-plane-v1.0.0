# 控制面

- **初始化**。收到「用控制面初始化」时，查[初始化步骤](references/initialize.md)。
- **推进项目**。已初始化的项目从 AGENTS.md 进入本地工作流程。共用流程的源码在[每轮工作](references/runtime/control-plane/workflow.md)。
- **协作记录**。「把我上面的所有痛点综合起来阐述」或点名登记、续谈、归档、整理某类事项时，按项目入口执行[痛点综合](references/runtime/control-plane/pain-point-synthesis.md)或[搁置讨论](references/runtime/control-plane/deferred-discussion-list.md)。
