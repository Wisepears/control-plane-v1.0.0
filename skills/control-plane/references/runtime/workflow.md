# 控制面和领域面工作流程

1. **当前目标和原话**。按项目 AGENTS.md 的最小必读集开工。逐字同步本轮有信息量的新原话，核对总体目标和当前阶段目标，从用户的问题域形成或修正当前理解。项目使用自己的术语、材料与限定范围。
2. **内核工作流程【1】**。用[【1】](communication-core.md#part-1)组织问题。追问暴露理解断裂时，在上一版的基础上用[【2】](communication-core.md#part-2)重构。需要解释存在动机、原理、逻辑流转或数据流转时，接着用[【3】](communication-core.md#part-3)。组合照[工作流程原话](#intent-workflow)。判断依赖词义、决定或证据时走[领域查找](domain-modeling.md)，定位相关项后回到本轮问题。
3. **本轮入口**。从[关于产出](outputs.md)选做法，沿入口执行并[同步知识](communication-core.md#关于知识同步)。继续推进可处理的下一步。追问以用户新原话、上一版结果和新理解为基础，回到第 2 步。
4. **交付和主导**。用[交付模板](#交付模板)核对实际进展、当前问题和下一步。把下一件事、它解决的缺口和完成依据写回项目 UNDERSTANDING.md 的「主导」。

## 交付模板

开工说明使用实际采用的引导词，例如「我先核对当前目标和决定索引，再用内核工作流程【1】对齐你问的范围」。交付给出用户目标的实际进展、当前问题的答案以及下一步主导计划。结论附相关原话、决定或证据。
