# 搁置讨论清单

## 我的触发词

| 我发的请求 | 用法 |
|---|---|
| 把我搁置的讨论列起来 | 把对话中的清单答复原样追加到[清单](../../搁置讨论清单.md) |
| 继续讨论「事项」 | 找到该条及原话，从当时搁置的地方继续 |
| 归档搁置讨论「事项」 | 把原条目和对话中已有的结论移植到[归档](../../搁置讨论归档.md) |
| 整理搁置讨论清单 | 沿已有原文整理，重合处保留一份原文和出处 |

## 使用方法

整理清单时，查[Pruning 原文](../skills/mattpocock/writing-for-agents/writing-for-agents.md#pruning)，交付前[核对实际改动](../关于内容维护.md#check-edits)。

- 登记和续谈有新进展时，按[追加原话](../../ORIGINAL-INTENT.md#u130)更新[清单](../../搁置讨论清单.md)。本轮需要先形成答复时，查[产出原则原话](../communication-core.md#production-principles)。
- 讨论已有明确结论或用户明确终止时，可以主动提请归档。固定句式是「关于『{事项}』，讨论已经收敛到{结论}。可以把原条目和结论写入《搁置讨论归档》吗？」
- 用户点名归档或确认后，在归档末尾依次追加清单条目原文和对话中已有的结论原文。两段文字逐字核对后，清单原处指向归档。尚待实施的工作按原有任务记录追踪。
- 查归档时按事项定位。整理完成后，核对仍搁置的问题都有去处，并且恢复任何一条时能找到原话和讨论到的位置。
