## 动作输出模板

1. **过程播报。** 每步先说“接下来我将用【引导词】做【动作】”，并给出动作过程和结果
2. <a id="write-back"></a>**即时写回（如触发）。** 写回【内容】到【位置】，依据【出处】。 [写回位置](workflow.md#write-back-locations)
3. **动作过程和结果** 按主体节写。涉及流程时，说明输入如何变成输出，给一个具体用例供核对。
4. **下一步主导。** 写下一件要做的事、它要解决的缺口和完成依据，更新到[主导栏目](../../UNDERSTANDING.md#leadership)。
5. **核验。**本次动作和产出是否符合大脑方法论以及mermaid节点上层动作所需的前文一切内容（如最小必读集和大脑方法论，或经过了关于内容维护），未满足项标出并重新本步。

<a id="output-template"></a>
## 整体输出模板

一轮结束时按此收口：

1. **最终验收。** 本轮节点流序如“A->B->C...”，供核对是否跳步。 [Premature Completion](../skills/mattpocock/writing-great-skills/GLOSSARY.md#premature-completion)
2. **目标进展。** 本轮解决了什么。用正文、查证结果或验证结果说明进展。
3. **下一步主导。** 写下一件要做的事、它要解决的缺口和完成依据，更新到[主导栏目](../../UNDERSTANDING.md#leadership)。

## 主体

1. 叙述需要引用的控制面、问题域、实现域的GLOSSARY
2. 叙述需要引用公理定理（如有）
3. 叙述需要引用的ADR（如有）
4. 动作的分析过程和结果
5. 测试用例或场景实例(如需要用于解释)
