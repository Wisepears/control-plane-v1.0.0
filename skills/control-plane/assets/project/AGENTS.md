## 每轮必读

**控制面始终是项目内最高优先级。** 每轮开工先按顺序读最小必读集，再按触发条件补读。见[U46](ORIGINAL-INTENT.md#u46)、[U84](ORIGINAL-INTENT.md#u84)、[U123](ORIGINAL-INTENT.md#u123)、[U169](ORIGINAL-INTENT.md#u169)。

### 最小必读集

1. [`foundation/communication-core.md`](foundation/communication-core.md)。读交流内核及产出与问题探讨的规则。
2. [`OBJECTIVE.md`](OBJECTIVE.md)。核对当前目标。
3. [`UNDERSTANDING.md`](UNDERSTANDING.md)。核对对控制面和问题域的当前理解。
4. [`ORIGINAL-INTENT.md`](ORIGINAL-INTENT.md#intent-purpose)。读[目标原话](ORIGINAL-INTENT.md#u19)、[协作原话](ORIGINAL-INTENT.md#u129)和本轮相关原话的完整条目。按当前问题定位条目。
5. [`ADR.md`](ADR.md)。读决定索引，相关决定的正文按条目补读。
6. [`GLOSSARY-MAP.md`](GLOSSARY-MAP.md)。按当前问题定位到对应上下文的词汇表条目。

### 触发补读

- 首次接手读完[控制面导航与交接](foundation/README.md)。后续需要找控制面规则、领域面正文或交接说明时，从该页目录定位。
- 本轮任务材料按任务自己的读取范围读。如果本轮判断依赖尚未读取的词义、决定或证据，沿对应入口补读，再继续。

对照本轮适用的控制面原话逐句核对理解，再读取本轮任务材料。交付时说明实际采用的引导词和由此采取的动作。见[U46](ORIGINAL-INTENT.md#u46)、[U169](ORIGINAL-INTENT.md#u169)。

读完必读材料后，本轮任务走[控制面和领域面工作流程](foundation/control-plane/workflow.md#workflow)。

受限任务按各自资料包的读取范围执行。
